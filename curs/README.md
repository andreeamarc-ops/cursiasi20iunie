# Atelier: Claude, colegul tău la job

Pachet de atelier care se predă singur, pentru profesioniști de birou. Înveți să folosești **Cowork** (spațiul de
lucru din aplicația Claude — folder + panou de fișiere, fără terminal și fără cod) pe sarcini reale de birou.

➡️ **Deschide [START-HERE.md](START-HERE.md)** și urmează cei 3 pași.

Pe scurt: deschizi acest folder ca proiect în Cowork, scrii `start`, și parcurgi 12 cursuri scurte, unul pe rând.
Toată ziua lucrezi în aceeași firmă fictivă — **Nordica** — din șapte unghiuri (PM, content, HR, financiar,
procurement, legal, antreprenor), iar la final pleci cu un workflow real și **cel puțin un skill propriu**. Cele
șapte **Starting Kit-uri** sunt în `skills/` și sunt hărtuite în [STARTING-KITS.md](STARTING-KITS.md). (Sala e
formată numai din femei — toate personajele Nordica sunt femei.)

Atelierul e construit pe aceeași structură ca atelierul-soră **Claude Code pentru cercetare**, reskinuit pentru
muncă de birou și ancorat în firma Nordica. Firul roșu rămâne același: **AI = instrument, nu sursă de adevăr; omul
deține fiecare decizie.**

Materialele:

- `lessons/` — cele 12 scripturi de curs (le citește Claude, nu tu).
- `scenarii/` — datele fictive Nordica pe care lucrăm.
- `skills/` — cele 7 Starting Kit-uri (skill-uri pre-construite, ~27 skill-uri, inclusiv ANAF prin MCP).
- `templates/` — șabloane (fișă de post, status report, raport lunar).
- `reference/` — context read-only (firma Nordica, glosar, busola de decizie).
- `inbox/`, `processed/`, `outputs/` — unde pui fișiere noi și unde scrii rezultatele.
