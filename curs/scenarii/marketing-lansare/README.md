# marketing-lansare/ — anunțul de lansare v2.0 (Nordica, fictiv)

Materialul pentru **Cursul 9** (marketing). Conține `brief-anunt-v2.md` — faptele despre lansarea Nordica
Booking v2.0, din care se scrie un text de anunț folosind skill-ul `reguli-de-casa` (regulile casei). Apoi textul
e trecut prin **3 subagenți** cu trei perspective diferite: **PR**, **jurnalist sceptic** și **client potențial**.

Notă pentru trainer: brieful conține deliberat lucruri „posibile, nu garantate" (SMS la lansare) și interdicții
clare (fără superlative, fără cifre inventate). Dacă textul scapă o promisiune neacoperită, **jurnalistul sceptic**
trebuie să o prindă — exact reflexul „verifică în sursă" aplicat unui text public.
