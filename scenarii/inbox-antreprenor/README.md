# inbox-antreprenor/ — dimineața Andreei (Nordica, fictiv)

update-uri interne, spam, întrebare de presă despre v2.0) și calendarul de azi (~6 evenimente) ale fondatoarei
Andreea Pop — toate **fictive**. Folosit la **Cursul 11** (antreprenor): construirea unui digest zilnic din inbox +
calendar. Linia roșie: digestul *adună și schițează*, omul decide și trimite.
